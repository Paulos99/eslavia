# Заявки на Яндекс.Почту

Форма «Получить прайс» на сайте отправляет письмо на ящик из `data/lead-mail.json` → поле `to`.

Сейчас для теста указан `pavel199975@ya.ru`. Чтобы сменить адрес, замените это поле (или задайте `MAIL_TO` / `VITE_LEAD_EMAIL` в `.env`).

Первая заявка через FormSubmit присылает на этот ящик письмо с подтверждением. Нужно открыть его и нажать Activate — после этого заявки начнут приходить как обычные письма.
