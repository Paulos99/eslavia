# UX-спецификация — Таисия

Одностраничный каталог женского трикотажа. Не магазин: нет корзины, оплаты и кабинета.

## Информационная архитектура

```
HEADER (sticky)
HERO
КАТЕГОРИИ
КАТАЛОГ (фильтры + поиск + сетка + «Показать ещё»)
О КОМПАНИИ
ОПТОВЫМ ПОКУПАТЕЛЯМ (форма → Telegram → PDF)
ТАБЛИЦА РАЗМЕРОВ
КОНТАКТЫ / ДОСТАВКА
FOOTER
```

Единственный отдельный маршрут: `/privacy`.

## Сценарии

### Розница
1. Понять за 3 секунды: женский трикотаж, опт и розница.
2. Выбрать категорию → якорь в каталог с активным фильтром.
3. Найти модель (поиск по названию / артикулу).
4. Открыть карточку → розничная цена, размеры, фото.
5. Связаться по телефону / мессенджеру.

### Опт
1. CTA «Получить оптовый прайс» виден в header, hero и отдельном блоке.
2. Имя + контакт + согласие на ПДн.
3. Заявка уходит в Telegram.
4. После успеха — скачать PDF. Оптовые цены в каталоге не показываются.

### Мобильный
- Sticky header: логотип, hamburger, CTA.
- 2 карточки в ряд.
- Фильтры — bottom sheet.
- Товар — полноэкранный modal.
- Touch target ≥ 44px.

## Навигация

Якоря: `#catalog`, `#about`, `#wholesale`, `#contacts`.  
Категории скроллят к `#catalog` и выставляют фильтр категории.

## Каталог

- Фильтры: категория, размер, поиск. Цвет — только если в данных появятся значения (сейчас пусто).
- Сортировка не нужна (мало SKU).
- Первые 12 карточек, далее «Показать ещё» по 12.
- Карточка: фото, название, артикул, розница, размеры. Hover: scale 1.03, второе фото, «Подробнее».
- Клик → drawer (desktop справа) / full-screen (mobile). Закрытие: крестик, Escape, overlay. Focus trap.

## Форма опта

Не имитировать успех, если Telegram недоступен. PDF показывается только после `ok` от API. Чекбокс обязателен, ссылка на `/privacy`.
