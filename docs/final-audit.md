# Финальный аудит

## Контент

- Товаров на источнике (поиск): 38
- Товаров в новой базе: 38
- С изображениями: 37. Без фото: `mtk-116e` — на taisiy.ru placeholder.
- Все доступные розничные цены перенесены как на источнике, включая аномалию **Платье М-102Б = 325 000 ₽**.
- Оптовые цены в JSON и PDF, в каталоге UI не показываются.
- Пустые категории старого меню не выводятся.
- Факты компании, контакты, доставка, таблица размеров, политика ПДн — с текущего сайта, без выдуманных преимуществ.

## UX

- Hero сразу говорит: женский трикотаж оптом и в розницу.
- Каталог с поиском, категориями, размером, «Показать ещё».
- Карточка → drawer/modal, розничная цена видна.
- Путь опта: header / hero / блок / форма → Telegram (или mock) → PDF.

## UI

- Off-white, Manrope + Cormorant Garamond, акцент `#9A5B45`.
- Карточки без рамок, фото 3:4.
- Реальные фото товаров (просмотрены примеры МТК-104, М-101С).

## Tech

- `npm run build` проходит.
- Стек: Vite + React + TypeScript.
- API заявок: `POST /api/wholesale-lead`, токен только в `.env`.
- `LEAD_ADAPTER=mock` для локальной вёрстки.

## Lighthouse

Автопрогон Lighthouse в сессии не выполнялся (нет браузерного MCP). Ожидаемые риски: шрифты Google Fonts (FOIT/FOUT), вес фото. Рекомендация: self-host шрифты при публикации, если LCP < 90.

## Как запустить

```bash
npm install
# Telegram: заполнить TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID, убрать LEAD_ADAPTER=mock
npm run build
node server/index.mjs
```

Dev: `npm run dev` (проксирует форму через Vite middleware).
